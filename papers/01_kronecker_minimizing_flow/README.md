# Convergence of the minimizing flow on Kronecker quiver complexes

Bernd Johannes Wuebben. Originally dated 18 November 2026. Revised 19 November 2026.

[Paper page](https://bwuebben.github.io/papers/phase-flow-convergence-kronecker/) · [PDF](paper.pdf) · [Zenodo:24347557](https://zenodo.org/records/24347557)

Run `latexmk -pdf -halt-on-error paper.tex` from this directory.

Theorem 3.1 gives an elementary proof that the negative part of the Schur multiplier has trace at most one third of its trace on every positive semidefinite input. The three [supplementary programs and reference outputs](ancillary/) use Python and python-flint (0.9.0). Each script can be run from that directory.
